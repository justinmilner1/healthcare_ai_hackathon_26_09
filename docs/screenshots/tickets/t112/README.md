## The times

The answer writes 24-hour, locale-pinned times (`Sun 22:30`); the Spikes table formats the same instants in
the viewer's locale (`Sun 10:30 PM`). Both are the summary zone (`lib/sour.ts`), so the two read as one
reading each and a clinician has no arithmetic to do. Pinning is what keeps a seeded demo identical on every
box rather than drifting with the machine that ran `npm run seed`.
